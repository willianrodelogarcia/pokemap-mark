Áreas de hábitat (desde JSON)

Elige Pokémon y ubicación para cargar el área completa desde el JSON. Pulsa «Colocar marca aquí» para agregar la ubicación. El Nº Pokédex y el nombre del mapa se completan automáticamente; si marcas varias ubicaciones, se concatenan con coma.

Coordenadas manuales

Las coordenadas manuales siguen disponibles si necesitas ajustar una ubicación. Usa la escala de una imagen de 960×640 (se ajusta sola si tu mapa es de otro tamaño).

La URL de Cloudinary se obtiene automáticamente al terminar la subida. Se envía un registro por Pokémon con { pokemon_id, map_name, map_url }, compatible con public.pokemon_maps.

Avanzado: reutilizar la imagen base sin volver a subirla en cada prueba

Si vas a generar muchas variantes de la misma foto mientras pruebas trazos, puedes subir la imagen base una sola vez aquí. El GIF final igual necesita horneen los píxeles (por eso pesa lo que pesa), pero te ahorra subidas de prueba innecesarias antes de decidir el resultado final.
